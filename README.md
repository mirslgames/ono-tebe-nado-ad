# Оно тебе надо

Учебный проект Яндекс Практикума — одностраничный сайт аукциона вещей, в которые никто не верил.

## Ссылка на репозиторий

https://github.com/mirslgames/ono-tebe-nado-ad

## Технологии

HTML5, CSS3, Flexbox, CSS Grid, семантическая разметка.

## Запуск

Откройте файл `index.html` в браузере. Все изображения и шрифты находятся в проекте и доступны локально.
